# Project
Поиск и первичный анализ наборов данных по различным областям применения
В первом разделе исследуется набор табличных данных «NHL Player Database», содержащий статистику игроков НХЛ. Выполнена визуализация распределений, корреляционный анализ, фильтрация и добавление шума. Данные ориентированы на решение двух задач искусственного интеллекта: рекомендательной системы (поиск хоккеистов, наиболее похожих на заданного игрока) и бинарной классификации (оценка вероятности включения игрока в Зал хоккейной славы). 
Тип данных: табличные данные
Ссылка на набор данных: https://www.kaggle.com/datasets/flynn28/nhl-player-database
Второй раздел посвящен анализу многомерного временного ряда из набора данных SKAB. Проведена декомпозиция ряда, оценка отношения сигнал/шум и анализ выбросов. Набор данных предназначен для решения задачи обнаружения точечных и коллективных аномалий  в работе промышленного оборудования на основе показаний физических датчиков.
Тип данных: временные ряды
Ссылка на набор данных: https://www.kaggle.com/datasets/yuriykatser/skoltech-anomaly-benchmark-skab
В третьем разделе выполняется первичный анализ набора данных с изображениями дорожных дефектов. Проанализировано распределение объектов по классам, качество аннотаций и разрешение изображений. Данные предназначены для решения задачи детекции объектов и их классификации — автоматического обнаружения и классификации пяти типов дефектов дорожного покрытия.
Тип данных: изображения
Ссылка на набор данных: https://www.kaggle.com/datasets/ilsafshamsutdinov/road-damage-dataset-for-object-detection?select=road_damage_dataset
В четвертом разделе представлен анализ текстового корпуса отзывов о российских банках. Выполнена лемматизация, удаление стоп-слов, TF-IDF векторизация и реализован информационный поиск. Набор данных предназначен для решения задачи классификации текстов / анализа тональности — определения эмоциональной окраски клиентских отзывов.
Тип данных: текст
Ссылка на набор данных: https://www.kaggle.com/datasets/scorpy12/russian-bank-customer-reviews-dataset
